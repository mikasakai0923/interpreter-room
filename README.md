# 多言語通訳ルーム

QRコードを読み取るだけで入れる、多言語の会話ルームです。
自分の言語で話すか書くと、ほかの人には、それぞれの言語の訳と原文が届き、訳が読み上げられます。
参加者に、アプリのインストールやアカウントの登録は要りません。
ルームを作れるのは、合言葉を知っている人（主催者）だけです。

対応している言語：日本語、English、繁體中文、简体中文、한국어、Français、Español、Deutsch

## しくみ

```
参加者のスマートフォン ──→ このサイト（GitHub Pages。画面だけ）
        │
        └─ 発言 ──→ Google Apps Script（中継と翻訳） ──→ ほかの参加者のスマートフォン
                       └ 翻訳は、Apps Script に入っている Google 翻訳
```

- **画面**（このリポジトリ）：GitHub Pages で公開します。発言はここには置かれません。
- **中継と翻訳**（`gas/Code.gs`）：Google Apps Script のウェブアプリとして動かします。発言と訳は、最長6時間だけ Google 側に置かれ、自動で消えます。
- **声の聞き取りと読み上げ**：参加者のブラウザの機能を使います。
- **用語集**（`glossary.txt`）：Gemini を足したときに、音声入力の聞き取りの誤り（専門用語が別の語に置きかえられる）を直し、訳語をそろえるために読みます。

## はじめるとき

1. [Google 側の設定手順](docs/setup.md) のとおりに、中継プログラムを置き、合言葉を受け取ります（10分ほど）。
2. できた URL を `config.js` の `apiUrl` に入れます。
3. サイトを開いて合言葉を入れ、「ルームを作って入る」を押します。出てきたQRコードを相手に読み取ってもらいます。

## 使うときに知っておくこと

- 発言と訳が残るのは数時間です。1つのルームに置くのは、新しいほうから40件までです。
- Google 翻訳は、1日 5,000 回までです（訳す言語1つにつき1回）。
- 1つのルームに同時に入るのは、30人ほどまでを目安にしてください。
- ルームを作れるのは、合言葉を知っている人だけです。開いているルームには、リンクを知っている人ならだれでも入れます。
- ルームは、主催者の端末が出てから2時間たつと閉じます。主催者が同じリンクから入り直すと、また開きます。
- 声の聞き取りは、Safari（iPhone）と Chrome（Android・パソコン）で使えます。使えない端末では、キーボードから入力します。
- マイクの使い方は2つ（「招待」の中で切りかえ）：「タップ」は押して話し、もう一度押すと送る。「自動」は、黙るたびにそこまでを送って聞きつづける。

くわしくは [設定手順](docs/setup.md) の「知っておくこと」「うまくいかないとき」を見てください。

## ポケット通訳（1台で使う通訳）

`pocket.html` は、スマートフォン1台を通訳機にするページです。ルームも合言葉も使いません。

- 開く場所：<https://mikasakai0923.github.io/interpreter-room/pocket.html>
- 話した言語を自動で判別します。日本語は英語・中国語・台湾語に、英語・中国語・台湾語は日本語になり、文字と声で出ます。
- 録音は、「自動」（無音で区切って通訳をくり返す）と「タップ」（押して話し、もう一度押して通訳）を切りかえられます。
- 使う人が、自分の Gemini の API キーを「設定」に入れます。キーはその端末の中にだけ保存され、このサイトには置かれません。録音した声は、通訳のために Google（Gemini API）へ送られます。
- 「用語」で、専門用語を登録できます。書き方は `glossary.txt` と同じなので、そのまま貼り付けられます。
- 台湾語の読み上げは試験的です（Gemini は台湾語を正式な対応言語にしていません）。

## フォルダの中身

| 場所 | 中身 |
| --- | --- |
| `index.html`, `css/`, `js/` | 画面 |
| `pocket.html` | ポケット通訳（1台で使う通訳。このファイルだけで動きます） |
| `config.js` | サイトの設定（中継プログラムの URL） |
| `gas/Code.gs` | 中継と翻訳のプログラム（Apps Script に貼り付けるもの） |
| `gas/Gemini.gs` | 聞き取りの誤りを直し、訳の質を上げたいときに足す、追加のプログラム（なくても動きます） |
| `glossary.txt` | 用語集（Gemini を足したときに使われます。1行に1語、「日本語 = English」） |
| `vendor/qrcode.js` | QRコードを描くための部品（Kazuhiko Arase 氏作、MIT ライセンス） |
| `docs/` | 設定の手順 |
| `tools/` | 開発用のテスト（公開中のサイトの動きには関係しません） |

## 開発用のテスト

```
node tools/test-backend.js   # 中継と翻訳のプログラムのテスト
node tools/e2e.js            # ブラウザを動かして、複数人で話す流れを確かめるテスト
```

どちらも、Google の「まね」をするプログラムを相手に動かします。Google の実物と、実物のスマートフォンでの確認は、[設定手順](docs/setup.md) の手順5で行います。
