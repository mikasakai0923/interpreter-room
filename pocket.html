ポケット通訳

話すと、その場で通訳します

  1. 「設定」を開いて、Gemini の API キーを入れます。
  2. 下のマイクを押して話します。
  3. 日本語は英語・中国語・台湾語に、英語・中国語・台湾語は日本語になります。

訳の文字を押すと、もう一度読み上げます。

設定

Gemini の API キー

キーはこの端末の中にだけ保存されます。録音した声は、通訳のために Google（Gemini API）へ送られます。

録音

まわりがうるさくて区切れないときは感度を下げ、小さい声を拾わないときは上げます。

話が切れなくても、この長さで区切って通訳します（自動のとき）。

話す言語

日本語を話したときに出す訳

読み上げ

声に出す言語

台湾語は端末に声がないため、Gemini の音声で読みます。Gemini は台湾語を正式な対応言語にしていないので、発音は確かめてから使ってください。数秒かかります。

切っておくと、読み上げの声をマイクが拾って訳し直すのを防ぎます。イヤホンで聞くときは入れると、話しながら訳が流れます。

記録

くわしい設定（モデル名）

用語の登録

聞き取りの誤りを直し、訳語をそろえるために使います。1行に1語、「日本語 = English」。英語のあとに「|」で中国語・台湾語の訳も足せます。用語だけの行は、聞き取りの修正にだけ使います。「#」で始まる行は読み飛ばします。
